## 🎯 Overview
This project leverages **Supervised Machine Learning** to predict calories burnt during physical activities. By analyzing physiological metrics like heart rate and body temperature, the model provides high-precision energy expenditure estimations.

### 🌟 Key Features
- 📊 **Multivariate Regression** - Lasso, Ridge, and Random Forest analysis.
- 🚀 **XGBoost Integration** - High-performance gradient boosting.
- 🔍 **Feature Importance** - Discovering key calorie drivers.
- 📈 **Predictive Insights** - Data-driven health monitoring.

---

## 📂 Dataset Intelligence

| Attribute | Description | Impact |
|-----------|-------------|--------|
| **Heart Rate** | Processing during exercise | High |
| **Duration** | Length of activity (min) | Very High |
| **Body Temp** | Core temperature tracking | Moderate |
| **User Bio** | Age, Height, Weight | Basal Met. |

## 🛠️ Technology Stack
- **Core Engine**: `Python 3.x`
- **Linear Algebra**: `NumPy`, `Pandas`
- **Visual Analytics**: `Matplotlib`, `Seaborn`
- **Intelligence**: `Scikit-Learn`, `XGBoost`

## 🚀 Deployment Guide
1. Clone the repository:
   ```bash
   git clone https://github.com/HarshChoudhary2003/Machine_Learning_Projects.git
   cd "Calories Burnt Prediction using Machine Learning"
   ```
2. Setup Environment:
   ```bash
   pip install pandas numpy scikit-learn matplotlib seaborn xgboost jupyter
   ```
3. Launch Analysis:
   ```bash
   jupyter notebook main.ipynb
   ```
