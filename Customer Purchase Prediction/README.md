## 🛍️ Overview
This project uses **Classification Algorithms** to predict customer purchase intent based on demographic and behavioral signals. By identifying high-probability buyers, businesses can optimize marketing spend and personalize user experiences.

### 📊 Behavioral Data Pipeline
The system analyzes 1,000+ data points across:
- 👤 **Demographics**: Age, Income, Gender, City.
- 🖱️ **Session Data**: Time on site, pages viewed.
- 🎯 **Conversion**: Purchase binary status.

---

## 🧠 Diagnostic Methodology
1. **EDA**: Correlation analysis between 'Pages Viewed' and 'Conversion'.
2. **Preprocessing**: One-Hot Encoding for categorical features & Standard Scaling.
3. **Modeling**:
   - **Logistic Regression**: Baseline performance.
   - **Random Forest**: High-fidelity feature interaction learning.
