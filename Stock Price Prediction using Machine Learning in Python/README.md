## 🎯 Overview

This project explores various machine learning techniques to predict stock prices. By analyzing historical market data, the models learn patterns that help forecast future price movements.

### 🌟 Techniques Used
- 📊 Time series analysis
- 🧠 Deep learning (LSTM/RNN)
- 📈 Technical indicators
- 📉 Trend analysis

---

## 📊 Dataset

| Attribute | Description |
|-----------|-------------|
| **File** | `Tesla.csv` |
| **Size** | ~110 KB |
| **Features** | OHLCV (Open, High, Low, Close, Volume) |

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📈 **Price Prediction** | Forecast closing prices |
| 📊 **Visualization** | Interactive price charts |
| 📉 **Trend Analysis** | Identify market trends |
| 🔄 **Moving Averages** | SMA, EMA calculations |
