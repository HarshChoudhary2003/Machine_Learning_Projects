## 📄 Overview

The **AI-Powered Resume Screening App** is an interactive **Streamlit** platform that leverages **Machine Learning and NLP** to revolutionize the recruitment workflow. It analyzes resumes, extracts key skills, and classifies candidates into precise job categories with high confidence.

### 🌟 Key Objectives
- 🔍 **Automated Screening** - Reduce manual resume review time by 80%.
- 📊 **Talent Analytics** - Visualize candidate distribution across categories.
- 🎯 **JD Matching** - Rank candidates based on job description similarity.

---

## ✨ Features

- 📤 **Multi-Format Upload** - Support for PDF, DOCX, and TXT files.
- 🛡️ **Glassmorphism UI** - Modern, premium user interface with animations.
- ⚡ **Batch Processing** - Screen hundreds of resumes in seconds.
- 📈 **Interactive Visuals** - Plotly-powered distribution charts.
- 📥 **Intelligence Export** - Download results in CSV/Excel format.

## 🚀 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/HarshChoudhary2003/Machine_Learning_Projects.git
   cd "Resume Screening App"
   ```

2. **Environment Setup**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch System**:
   ```bash
   streamlit run app.py
   ```

---

## 🛠️ Tech Stack

- **Frontend**: Streamlit (Glassmorphism UI)
- **NLP**: NLTK, Scikit-Learn (TF-IDF Vectorization)
- **ML**: Support Vector Machine (SVM) / Random Forest
- **Data**: Pandas, NumPy
- **Visuals**: Plotly, Lottie Animations
